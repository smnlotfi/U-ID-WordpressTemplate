برای دیدن موارد بعدی، بکشید

تمام وب‌سرویس‌ها RESTful هستند. برای شروع فقط به یک شناسه کسب‌وکار و یک آدرس بازگشتی نیاز دارید.

// آدرس وب‌اپلیکیشن را با پارامترها بسازید و کاربر را به آن هدایت کنید
https://cloud.uid.ir/crypto/?requestBusinessId=UID_BUSINESS_ID
                            &metaData=METADATA
                            &phoneNumber=PHONE_NUMBER
requestBusinessId الزامی است و توسط یوآیدی در اختیار شما قرار می‌گیرد. phoneNumber محدودکننده نیست و صرفاً تسهیل‌گر است — کاربر می‌تواند با ویرایش URL آن را تغییر دهد.
// پس از خاتمه فرآیند، کاربر به آدرس اعلامی شما بازمی‌گردد
BUSINESS_REDIRECT_URL/?clientToken=CLIENT_TOKEN
                       &metaData=METADATA
                       &status=STATUS

// نمونه status ها
1   SUCCESS                       احراز هویت با موفقیت به پایان رسید
2   RESULT_CAMERA_NOT_SUPPORTED   دوربین پشتیبانی نمی‌شود
3   RESULT_PERMISSIONS_NOT_GRANTED دسترسی دوربین داده نشد
7   RESULT_ALREADY_APPROVED       کاربر قبلاً فرآیند را طی کرده
10  RESULT_LIVENESS               ویدئوی سلفی ناموفق بود
11  RESULT_FACE_MATCHING          عدم تطابق با ثبت احوال
این وضعیت‌ها مربوط به «فرآیند احراز هویت» هستند، نه نتیجه آن. برای اطلاع از نتیجه، باید با یک فاصله زمانی سرویس getUserInfo فراخوانی شود.
POST https://api-crypto.uid.ir/business/login

Content-Type: application/json;charset=UTF-8
{
  "id": <UID_BUSINESS_ID>,
  "secretKey": <UID_SECRET_KEY>
}

// پاسخ
{
  "message": { "oauthInformation": {
      "access_token": ACCESS_TOKEN,
      "token_type": "bearer",
      "scope": "[read, write]" } }
}
شناسه کسب‌وکار و کلید محرمانه توسط یوآیدی در اختیار شما قرار می‌گیرد. تمام وب‌سرویس‌ها RESTful هستند.
POST https://api-crypto.uid.ir/getUserInfo

Authorization: bearer access_token
Content-Type: application/json;charset=UTF-8
{ "clientToken": <CLIENT_TOKEN> }

// پاسخ — اطلاعات کامل و تاییدشده کاربر
{
  "status": SUCCESS,
  "name", "family", "nationalCode",
  "mobileNumber", "birthDate", "metaData",
  "bankInfo":    { shabaNumber, bankName, cardNumber, accountNumber },
  "addressInfo": [ { state, city, userAaddress, postalCode } ]
}
به دلیل محدودیت‌های سازمان ثبت احوال، دریافت اطلاعات کاربر پس از حداقل ۱۰ دقیقه امکان‌پذیر است. برای دریافت گروهی، سرویس getUserInfo/bulk با آرایه‌ای از clientTokenها در دسترس است.

پیش از تصمیم

سوال‌هایی که معمولاً قبل از امضا پرسیده می‌شود

یوآیدی‌پلاس یک راهکار تحت وب است که با کمترین بار توسعه فنی و عملیاتی طراحی شده. شما فقط یک URL را با پارامترهای مشخص فراخوانی می‌کنید؛ کل فرآیند احراز درون راهکار یوآیدی طی می‌شود و در پایان، کاربر به آدرس بازگشتی شما هدایت و نتیجه اعلام می‌شود. عملاً یک لینک، نه یک پروژه توسعه.

خیر. ملاک محاسبه هزینه، احراز هویت خاتمه‌یافته است و بابت فرآیندهایی که به هر دلیلی نیمه‌کاره رها شده‌اند هیچ هزینه‌ای دریافت نمی‌شود. علاوه بر این، یوآیدی کاربران رهاکرده را از طریق پیامک، تماس تلفنی و کانال‌های دیگر تا خاتمه فرآیند راهبری می‌کند.

شخصی‌سازی بصری بخشی از سرویس است: امکان درج لوگو، بنر و انطباق بر هویت بصری پذیرنده وجود دارد. همچنین با قابلیت Dynamic Flow، مراحل احراز بر اساس درخواست شما قابل مدیریت است — یعنی می‌توانید فقط مراحلی را فعال کنید که برای کسب‌وکارتان الزامی است.

خیر. معماری Multi-Vendor یعنی برای هر سرویس از چند تامین‌کننده استفاده می‌شود تا پایداری محصول حفظ شود. آپ‌تایم تعهدی سرویس‌های مرتبط با احراز یکپارچه ۹۹٫۵٪ است و به SLA فیمابین متعهد هستیم.

بر عهده یوآیدی. پاسخ‌گویی استعلامات قضائی (فتا) در کمتر از ۱ ساعت انجام می‌شود و ارسال استعلامات احراز هویت افراد به پلیس فتا یا مراجع قضائی در کمتر از ۳۰ دقیقه صورت می‌گیرد. علاوه بر این، دسترسی به سرویس کشف و پیشگیری از تقلب (FDP) یوآیدی رایگان در اختیار شماست.

پس از پایان فرآیند، یک clientToken به آدرس بازگشتی شما ارسال می‌شود و با فراخوانی سرویس getUserInfo می‌توانید اطلاعات کامل کاربر شامل مشخصات هویتی، اطلاعات بانکی و آدرس را دریافت کنید. برای دریافت گروهی، سرویس getUserInfo/bulk در دسترس است.
